同步热路径：只保留必要校验

Gateway → 订单 → 营销试算 → Redis Lua 原子锁定

Lua 一次完成资格、活动库存、团名额、参与次数与幂等键；成功后创建待支付订单。

OpenFeign 只用于查询与强一致前置校验，必须设置超时、隔离和降级。

异步交易链路：Kafka + Outbox / Inbox

支付成功 → 成团判定 → 库存确认 → 交易结算

按 orderId 或 groupId 选择 Partition；消费者以 eventId + 业务唯一键幂等。

重试 Topic、死信 Topic、补偿扫描共同处理丢失、重复、乱序与宕机恢复。
