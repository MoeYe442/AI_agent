企业知识工作台 - 推荐架构

Java 守住业务与权限边界，Python 负责 AI 编排与检索推理

用户入口
Vue 3 + TypeScript 工作台
知识库
Agent 对话
报告任务
管理与审计
↓ HTTPS / SSE
Spring Boot 平台服务

可信业务控制面

  • 登录、管理员 / 员工权限
  • 知识库与文档生命周期
  • Agent 任务、状态、报告版本
  • 调用授权、审计日志、流式转发

原则：Python 不能绕过 Java 直接决定用户权限。

FastAPI + LangGraph Agent 服务

AI 执行面

  1. 规划 Agent：拆解报告任务
  2. 检索 Agent：混合检索并整理证据
  3. 撰写 Agent：生成带引用初稿
  4. 审核 Agent：检查引用与完整性

原则：图状态可恢复，每一步都有结构化输入输出。

↓ 内部 REST + SSE 事件

PostgreSQL + pgvector

用户、文档元数据、任务、审计、文本块与向量统一存储。

MinIO

保存 PDF、Markdown、TXT 原文件与最终报告文件。

OpenAI 兼容模型端点

聊天模型与嵌入模型通过配置切换，不写死供应商。

核心数据流

上传：管理员上传文档 → Java 校验并保存 → Python 异步解析、切块、嵌入 → Java 展示索引状态。

报告：员工提交主题 → Java 创建任务并授权知识库 → 多 Agent 逐步执行 → SSE 实时显示进度 → Java 持久化带引用报告与审计记录。

MVP 优点

  • Java/Python 分工明确
  • 多 Agent 可观测、可测试
  • 单机 Docker Compose 可演示

刻意不做

  • 多租户与文档级 ACL
  • 通用自主工具市场
  • 消息队列与 Kubernetes
