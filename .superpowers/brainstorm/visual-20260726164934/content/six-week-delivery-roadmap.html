个人作品集：6 周交付路线与验收

目标是可运行、可演示、可故障复现、可压测的工程闭环；八个业务边界独立进程，但用单仓库与统一脚手架控制个人开发成本。

单仓库布局

platform-java

Maven 多模块：Gateway、八个业务服务、MCP Server、契约与测试支持。

ops-agent-python

FastAPI、LangGraph、OpenAI 兼容模型接入、诊断评测集。

web

Vue 3 Monorepo：user-web 与 admin-web，共享 API SDK 和 UI 基础包。

deploy / tests

Docker Compose、Nacos 配置、可观测配置、契约/E2E/压测/故障脚本。

六周里程碑

第 1 周 · 基座

Monorepo、Compose、Gateway、Nacos、JWT/RBAC、用户/商家模型、统一错误与 TraceId。

第 2 周 · 商品营销库存

商品与活动 SKU、LiteFlow 试算快照、活动库存池、Redis Lua 预占与补偿。

第 3 周 · 拼团交易

拼团/订单聚合、模拟支付、Outbox Relay、Kafka 事件、正常成团链路。

第 4 周 · 逆向与前端

超时关单、失败团退款、库存校正、商家/团长结算；用户端和管理端闭环。

第 5 周 · 稳定性与压测

Sentinel、线程池隔离、ELK、Prometheus/Grafana；基线对比、故障注入和调优。

第 6 周 · AI 与交付

Java MCP、Python Agent、五类诊断样例、演示数据、架构文档、压测报告和录屏脚本。

Docker Compose 运行档位

core：MySQL、Redis、Kafka、Nacos、Gateway、八服务、前端。

observability：在 core 上增加 Elasticsearch、Logstash、Kibana、Prometheus、Grafana。

ai：在 observability 上增加 MCP Server 与 Python Agent。

单 MySQL 实例承载独立 schema/账号；服务禁止跨 schema 查询。

公共契约约束

REST 统一 ApiResponse<T>、错误码与 Idempotency-Key。

金额统一使用 long cents，时间统一 UTC ISO-8601，外部 ID 按字符串传输。

Feign DTO 与 Kafka Event DTO 独立版本化，不共享领域实体或 MyBatis PO。

接口通过 OpenAPI 生成 TypeScript SDK；事件通过 JSON Schema 做兼容检查。

测试与验收金字塔

领域单测

价格策略、状态迁移、退款/结算计算、重复与非法命令；不依赖 Spring 容器。

集成与契约

Testcontainers 启动 MySQL、Redis、Kafka；验证 Lua、Outbox/Inbox、DDL 唯一键和事件兼容。

端到端与故障

Playwright 覆盖开团到结算；注入重复回调、消费者宕机、Kafka 恢复和迟到支付。

Agent 评测

五类固定故障样例；每条事实必须引用工具证据，根因至少进入 Top-2，证据不足必须拒答。

1000 并发压测口径
同硬件、同数据、同脚本对比数据库锁基线与 Redis Lua 方案

预置固定活动、库存、用户池和团规模；记录 CPU、内存、容器配额、JVM 参数、Kafka Partition 数和数据库配置。

每轮先预热 5 分钟，再以 1000 VU 测量 10 分钟，至少运行 3 轮，报告中位 TPS、P95/P99、错误率和资源利用率。

硬性正确性门槛：零超卖、零重复有效参团、支付/退款/结算无重复记账，停止流量后补偿任务使不一致数收敛为 0。

性能表达：530→830 TPS 和 56.6% 作为待复现实验目标；只有真实报告达到后才能写成项目结果。

  • 不接真实支付和真实资金分账
  • 不做仓库调拨与提货点库存

  • 不把示例 TPS 冒充实测结果
